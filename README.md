# Trabalho de IA - Criar esteira de aprendizado de máquina
Objetivo: uma esteira de aprendizado de máquina que possui desde a etapa de preparação dos dados até a avaliação de um modelo.

### Base de Dados
Foi utilizada o dataset Turkish Music Emotion, disponibilizado no repositório UCI Machine Learning Repository.
A base contém informações acústicas de músicas, representadas por 50 características numéricas, além da coluna Class, que identifica a emoção associada a cada música.

Fonte: https://archive.ics.uci.edu/dataset/862/turkish+music+emotion

### Como executar o projeto?
1. Acesse o notebook disponibilizado neste repositório.
2. Abra o arquivo no Google Colab.
3. Faça download do dataset pelo UCI Machine Learning Repository (link disponibilizado acima).
4. Execute as células do notebook na ordem apresentada.
*(obs: ao executar a primeira célula, é preciso importar o arquivo CSV do dataset que baixamos anteriormente.)*
